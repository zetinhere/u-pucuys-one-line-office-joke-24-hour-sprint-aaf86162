A one-line office joke about the "per my last email" standoff, written to `/output/entry.txt` by `main.py` for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty.

## Run it

```sh
python3 main.py
```

The program validates the joke against the gate (UTF-8, 1–200 characters, a single line), writes it to `/output/entry.txt`, then reads it back and re-validates it before reporting success. Pass `--output-dir DIR` to write somewhere else for a local run.
